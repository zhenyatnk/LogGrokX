# Перенос профилей из LogGrokCore

## Что перенесено и какую проблему решает

| Изменение | Что даёт |
| --- | --- |
| Именованные профили с отдельными форматами разбора и правилами цветов | Настройки разных типов логов не смешиваются в одном общем наборе. |
| Вкладка `Profiles` в настройках: выбор, переименование, создание, копирование и удаление | Профили можно редактировать через интерфейс; черновики сохраняются при переходе между профилями до нажатия `Save`. |
| Выбор активного профиля в главном окне | Можно переключить формат уже открытых файлов без перезапуска приложения. |
| Повторный разбор открытых документов при изменении активного профиля | Колонки, время и подсветка сразу соответствуют новым настройкам, включая объединённый просмотр. Сохраняются порядок документов, активная вкладка, номера отмеченных строк, выбор источников и их цвета в объединённом просмотре. |
| Подготовка новых документов до замены старых | Если подготовить новый профиль не удалось, открытые документы и текущий выбор остаются доступны. |
| Проверка всех профилей при сохранении | Пустые и повторяющиеся имена, неправильные регулярные выражения, XOR и цвета не записываются через окно настроек. |
| Совместимость со старым конфигом и обновление по изменению файла | Существующие настройки продолжают работать, изменения YAML подхватываются текущим механизмом наблюдения за конфигом. |
| Объединение соседних красных правил `\tERR\t` и `\Werror\W` в `(?:\tERR\t|\Werror\W)` | Сокращает количество вызовов `IsMatch` с двух до одного для строк, не совпавших с первым старым правилом. Границы слова, регистр и приоритет исключений сохранены. Фактическое ускорение зависит от содержимого строк и отдельно не замерялось. |

## Хранение и применение

Используется прежний `appsettings.yaml` рядом с исполняемым файлом. Новые поля находятся в секции `Settings`: `Profiles` и `SelectedProfile`. Профиль содержит `Name`, `ColorSettings` и `LogFormats`.

Старый конфиг без `Profiles` представлен в интерфейсе как профиль `Default`. Если у профиля отсутствует секция цветов или форматов, она наследуется из старых общих настроек. `InheritLegacySettings: false` отключает это наследование. Сохранённые через редактор профили самостоятельные.

Новый комплектный конфиг включает:

- `Kaspersky` — прежние форматы и цвета LogGrokX;
- `Venn` — формат и цвета из Core, дополненные настройкой разбора времени;
- `Plain text` — отображение полного текста строки без правил подсветки.

Активный профиль общий для всех открытых документов. Выбор в главном окне применяется сразу и сохраняется. В окне настроек изменения применяются после `Save`; выбранный там профиль становится активным. Переключение с изменением форматов или цветов заново читает открытые файлы. Переименование или сохранение неизменённой конфигурации повторного разбора не вызывает.

Параметры времени, XOR и преобразования строк LogGrokX сохранены. При сохранении несвязанные секции YAML сохраняются. Неизменённая коллекция профилей не переписывается; при её редактировании коллекция записывается заново, поэтому комментарии внутри неё могут исчезнуть.

## Проверки

Добавлено 16 тестов: совместимость и наследование, сохранение и повторная загрузка YAML, обновление по изменению файла, редактор профилей и валидация, вставка ключей в YAML, переключение открытых документов, сохранение отметок и настроек объединённого просмотра, обновление активного профиля и неудачное переключение.

Дополнительно добавлено 14 проверок подсветки Kaspersky: оба варианта ошибки, границы слова, регистр, исключения и приоритет цвета при нескольких совпадениях.

Итоговая проверка: 333 теста прошли; пересборка решения — 0 предупреждений и 0 ошибок. Окно настроек проверено рендерингом в светлой и тёмной темах, включая узкую ширину окна.
