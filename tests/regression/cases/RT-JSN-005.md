## Цель

Регрессия #49: XML форматируется как JSON.

## Проверяемые требования

- `REQ-JSN-07` — XML-фрагменты (с `<?xml ...?>` или без) форматируются и сворачиваются, если у корня есть дочерние элементы; обобщения `List<int>`, `<br/>`, элемент только с текстом — не XML (#49).
- `REQ-JSN-08` — Unicode и escape-последовательности в JSON отображаются корректно; JSON внутри XML и XML внутри JSON.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `json-xml.log`, раскрыть `[X01]`. | XML с декларацией `<?xml version="1.0" ...?>` отформатирован: `order` → два `item` (`Widget`, `Gadget`), элементы сворачиваются. |
| 2 | Раскрыть `[X02]`. | `root` → `a` → `b`=`text`, пустой `c`; каждый многострочный элемент сворачивается. |
| 3 | Проверить `[X03]`, `[X04]`, `[X05]`. | Остаются обычным текстом: `List<int>`, `Dictionary<string, int>`, `<br/>`, `<root>text only</root>`. |
| 4 | Раскрыть `[X06]`. | JSON отформатирован; значение `xml` — строка `<r><a>1</a></r>` (валидный JSON). |
| 5 | Раскрыть `[X07]`. | XML отформатирован; текст `{"k":1}` внутри `data` сохранён. |
| 6 | Раскрыть `[J07]`. | `city` = `Москва`, `esc` = `AB` или исходное `\u0041\u0042` (без искажения), `quote` = `a"b`; кириллица читается. |

## Критерии прохождения
