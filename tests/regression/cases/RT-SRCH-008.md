## Цель

Проверить поиск с большим числом совпадений.

## Проверяемые требования

- `REQ-SRCH-10` — Большое число совпадений (тысячи) обрабатывается без зависаний, прогресс поиска виден.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `many-matches.log`, искать `bulk-match`. | `5000 matches` за ≤ 3 с; UI отзывчив. |
| 2 | Прокрутить список результатов до конца. | Последний результат `bulk-match 04999`. |
| 3 | Нажать `Shift+F3` с первой строки. | Переход к последнему совпадению (wrap-around), строка центрирована. |
| 4 | Искать `bulk-match 0[0-9]{3}7` с regex. | `500 matches`. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
