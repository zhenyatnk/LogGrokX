| Дефекты (регрессия) | — |

## Цель

Проверить присоединение строк без совпадения к предыдущей записи.

## Проверяемые требования

- `REQ-FMT-05` — Строки, не подходящие под формат, присоединяются к предыдущей записи (многострочные записи).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `classic-multiline.log`. | Отображаются 6 записей `[M01]`…`[M06]`. |
| 2 | Найти запись `[M02]`. | Запись содержит 3 строки продолжения: два `at LogGrokX.Demo...` и `continuation-only-token-QX7 ...`, они в поле Message той же записи, а не отдельными строками. |
| 3 | Выполнить поиск `QX7`. | 1 совпадение, указывающее на запись `[M02]`. |
| 4 | Выделить запись `[M02]`, `Ctrl+C`, `Get-Clipboard`. | Скопирована вся запись вместе с тремя строками продолжения. |
| 5 | Проверить `[M03]`, `[M04]`, `[M05]`. | Кириллица и японские символы отображаются корректно. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.
