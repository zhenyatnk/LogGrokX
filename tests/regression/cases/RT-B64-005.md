# RT-B64-005. Copy и Copy as native для декодированных значений

| Поле | Значение |
|---|---|
| ID | `RT-B64-005` |
| Область | B64 — Base64, PEM, сертификаты и ключи |
| Приоритет | P1 |
| Тип | Функциональный |
| Требования | `REQ-B64-08`, `REQ-HEX-04` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |
| Данные | `%RT%\testdata\binary\binary.log`<br>`%RT%\testdata\hex.log` |
| Ориентировочная длительность | 5 мин |
| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Проверить копирование.

## Проверяемые требования

- `REQ-B64-08` — Copy копирует отображаемый (декодированный) текст, Copy as native — исходный.
- `REQ-HEX-04` — HEX-кодированные DER/PEM сертификаты показываются как сводка (#75); Decode HEX в контекстном меню.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `binary\binary.log`, `BIN` у `[B03]`, выделить строку, контекстное меню → `Copy`; `Get-Clipboard`. | В буфере `payload={"id":42,"ok":true} accepted` (как отображается). |
| 2 | Контекстное меню → `Copy as native`. | В буфере исходный `payload=eyJpZCI6NDIsIm9rIjp0cnVlfQ== accepted`. |
| 3 | Открыть `hex.log`, `BIN` у `[H01]`, `Copy` и `Copy as native`. | `data=Hello world` и `data=48656C6C6F20776F726C64`. |
| 4 | Отжать BIN у `[B03]`, `Copy`. | Исходный Base64. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
