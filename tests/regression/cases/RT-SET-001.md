## Цель

Проверить окно настроек.

## Проверяемые требования

- `REQ-SET-01` — Окно Settings: вкладки View, Profiles (Colors, Log formats), Value mappings, Symbols, Debug; Save/Cancel; изменения применяются после Save.
- `REQ-SET-05` — Комментарии и неизвестные ключи YAML сохраняются при записи настроек через окно.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть Settings (кнопка в заголовке). | Вкладки `View`, `Profiles` (подвкладки `Colors`, `Log formats`), `Value mappings`, `Symbols`, `Debug`. |
| 2 | View: изменить Log font size на 16, нажать `Cancel`. | Размер не изменился; YAML не изменён (сравнить хэш `Get-FileHash`). |
| 3 | Снова изменить на 16 и `Save`. | Размер 16 применён; в `appsettings.yaml` `LogFontSize: 16`. |
| 4 | Проверить, что комментарии YAML (например `# BigLine: prune\|break`) сохранились. | Комментарии и порядок ключей сохранены. |
| 5 | Нажать `Open appsettings.yaml` (если доступно на вкладке). | Файл открыт в связанном редакторе. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Вернуть Log font size 12.
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
