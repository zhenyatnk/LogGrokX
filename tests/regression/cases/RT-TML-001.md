| Дефекты (регрессия) | — |

## Цель

Проверить фильтр по времени через таймлайн.

## Проверяемые требования

- `REQ-TML-01` — Таймлайн (минимап) отображает плотность всего файла и позволяет выбрать диапазон времени перетаскиванием маркеров.
- `REQ-TML-06` — Метки и результаты поиска отображаются на таймлайне; клик по таймлайну переходит к позиции.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `threads.log` (18 строк, 10:00:00.000…10:00:04.250). Убедиться, что таймлайн виден (View → Timeline → Timeline at top). | Таймлайн отображается над сеткой, показывает плотность строк. |
| 2 | Перетащить левый маркер диапазона примерно на середину. | Строки до выбранного времени скрыты; первая видимая строка соответствует выбранному времени. |
| 3 | Перетащить правый маркер левее конца. | Скрыты строки после выбранного времени. |
| 4 | Выполнить поиск `step 1` и нажать F3 несколько раз. | Совпадения вне диапазона не посещаются. |
| 5 | Пометить видимую строку; проверить таймлайн. | Метка отображается на таймлайне. Клик по месту метки переходит к строке. |
| 6 | Вернуть маркеры к краям (двойной клик/перетаскивание). | Все 18 строк видны. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта
