## Цель

Проверить отсутствие ложных срабатываний.

## Проверяемые требования

- `REQ-B64-04` — Декодируется только валидный UTF-8 без управляющих символов; GUID, hex, слова и бинарные данные не декодируются; URL-safe алфавит и отсутствие паддинга поддерживаются.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `binary\binary.log`, проверить `[B02c]` (`SGk=`). | Нет кнопки BIN (значение < 8 символов). |
| 2 | Проверить `[B04]` (`token=SGVsbG8=`). | Фрагмент < 16 символов — не декодируется. |
| 3 | Проверить `[B10]`. | GUID, `deadbeef…`, `ThisIsNotBase64Text`, `AAECAwQFBgcICQoLDA0ODw==` (бинарные данные) не декодируются; BIN отсутствует или не меняет эти значения. |
| 4 | Проверить `[B13]` (`BEGIN CERTIFICATE` … `END PUBLIC KEY`). | Несовпадающие маркеры: PEM не декодируется, аварии нет. |
| 5 | Открыть `search.log`, `hex.log`. | У строк с GUID/хэшами (`[S04]`, `[H07d]`, `[H07e]`) нет ложных декодирований Base64. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
