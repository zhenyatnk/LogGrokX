## Цель

Проверить нормализацию времени без даты.

## Проверяемые требования

- `REQ-TML-04` — Нормализация времени без даты: переход через полночь (откат > 1 ч = новые сутки), малые откаты выравниваются.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `time\midnight.log` (23:59:57.000 → 00:00:03.000). | 25 строк. |
| 2 | Навести курсор на правый край таймлайна. | Время около `00:00:03` — относится к следующим суткам (таймлайн не «сворачивается» назад; строки `[D13]`…`[D25]` правее `[D12]`). |
| 3 | Выбрать диапазон маркерами в правой половине. | Видны только строки после полуночи (`[D13]` и далее) — диапазон корректен. |
| 4 | Открыть `time\small-backjump.log` (строка `[R04]` на 2 с раньше предыдущей). | Таймлайн в режиме времени (не `Line N`); `[R04]` при наведении отображается не раньше `[R03]` (выравнивание малых откатов). |
| 5 | Выбрать диапазон, захватывающий `10:00:00.5`–`10:00:01.0`. | `[R04]` попадает в диапазон рядом с `[R03]`, порядок строк не меняется. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
