| ID | `RT-VM-003` |
| Область | VM — Маппинг значений |

## Цель

Проверить импорт/экспорт и валидацию.

## Проверяемые требования

- `REQ-VM-05` — Import JSON... (объект списка, массив списков, плоский объект `{value: mapping}`; замена по имени), Export list..., Export all...; ошибки импорта.
- `REQ-VM-06` — Предпросмотр Preview, валидация (пустое значение, дубликаты) и применение после Save к открытым строкам без переоткрытия (#58).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Settings → Value mappings → Import `vm-invalid.json`. | Сообщение `Cannot import vm-invalid.json: …`, существующие списки не изменены. |
| 2 | Импортировать `vm-list.json`, затем `vm-replace.json`. | `… 1 replaced by name. Save to apply.`; в `Reg-Types` одно значение `type 1 (replaced)`. |
| 3 | Выбрать `Reg-Types` → `Export list...` в `%TEMP%\lgx-vm-one.json`. | `Exported "Reg-Types" to …`; файл — JSON со списком. |
| 4 | `Export all...` в `%TEMP%\lgx-vm-all.json`. | `Exported N list(s) to …`; массив списков. |
| 5 | Добавить элемент без значения и дубликат `0x00001`, Save. | Ошибки `Value mapping list "Reg-Types" has an item without a value.` и `… has duplicate values: 0x00001.`; диалог автоисправления с `Fix all and save`. Ошибка про пустой элемент показывается отдельно, а не подменяется ошибкой о дубликатах; до подтверждения пустой элемент не удаляется молча (#125). |
| 6 | `Fix all and save`. | Пустой элемент удалён, дубликат удалён с сохранением первого. |
| 7 | `Cancel` без Save после импорта. | Импорт не применён. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Удалить импортированные списки, файлы `%TEMP%\lgx-vm-*.json`.
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
