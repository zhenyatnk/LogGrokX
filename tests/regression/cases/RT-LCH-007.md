## Цель

Регрессия #65: горячие клавиши поиска не работали до первого клика.

## Проверяемые требования

- `REQ-LCH-07` — Сочетания клавиш поиска работают сразу после старта, до первого клика по окну (#65).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Закрыть LogGrokX. Запустить `& "%APP%\LogGrokX.exe" "%RT%\testdata\search.log"` и НЕ кликать мышью по окну. | Окно активно, открыт документ `search.log`. |
| 2 | Сразу нажать `Ctrl+F` и набрать `payment`. | Фокус в поле поиска документа (`Search logs (Ctrl+F)`), введённый текст `payment` появился в поле, через ~0,5 с запущен поиск (Match case выключен): найдены строки `[S09]`, `[S10]`, `[S11]`, счётчик `3 matches`. |
| 3 | Повторить запуск и нажать `Ctrl+L`, затем ещё раз — `Alt+D`. | Оба сочетания переводят фокус в поле поиска и выделяют его текст. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
