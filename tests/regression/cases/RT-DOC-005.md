## Цель

Регрессия #73: закрытие вкладки во время загрузки.

## Проверяемые требования

- `REQ-DOC-06` — Закрытие вкладки во время загрузки/индексации не приводит к ошибке и освобождает файл (#73).
- `REQ-LRG-06` — Удаление/переименование файла на диске при открытом документе не приводит к аварии.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Сгенерировать файл: `& "%RT%\tools\New-LargeLog.ps1" -Path $env:TEMP\lgx-large.log -SizeMB 1024`. | Скрипт вывел Path, Lines, Bytes (~1 ГБ). |
| 2 | Открыть `$env:TEMP\lgx-large.log` и в течение первой секунды индексации закрыть вкладку. | Вкладка закрывается мгновенно (≤1 с), приложение не зависает, нет диалогов ошибок. |
| 3 | Сразу выполнить `Remove-Item $env:TEMP\lgx-large.log` (после 2 с ожидания). | Файл удаляется (не заблокирован LogGrokX). Если `IOException` — FAIL. |
| 4 | Сгенерировать файл заново, открыть, запустить поиск `L-ERR` и во время поиска закрыть вкладку. | Закрытие без ошибок; в `%LOCALAPPDATA%\LogGrokX\` нет записей о необработанных исключениях. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- `Remove-Item $env:TEMP\lgx-large.log`
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
