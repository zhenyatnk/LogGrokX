## Цель

Регрессия #43: мультивыбор результатов поиска.

## Проверяемые требования

- `REQ-SRCH-11` — Множественный выбор результатов поиска (Shift/Ctrl) и операции над ними (копирование, метки) (#43).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `search.log`, искать `order`. | 3 результата. |
| 2 | В списке результатов кликнуть первый, Shift+клик по третьему. | Выделены 3 результата. |
| 3 | `Ctrl+C`, `Get-Clipboard`. | Скопированы 3 строки `[S09]`, `[S10]`, `[S11]`. |
| 4 | Нажать `Space`. | Все три строки помечены; в Marked lines 3 записи. |
| 5 | Ctrl+клик по второму (снять из выделения), Space. | Снимаются метки только с выделенных (1-й и 3-й), если все выделенные были помечены. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
