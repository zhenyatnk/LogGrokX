## Цель

Регрессия #33: копирование без многоточий.

## Проверяемые требования

- `REQ-GRD-01` — Ctrl+C / Copy копирует выделенные строки полностью (без многоточий) в исходном виде (#33).
- `REQ-GRD-05` — Ширина колонки Message подгоняется по содержимому при загрузке.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `classic-multiline.log`. | Ширина колонки Message подогнана по содержимому. |
| 2 | Выделить `[M02]`, `Ctrl+C`, `Get-Clipboard`. | Многострочная запись целиком (стек и `continuation-only-token-QX7`), без `...`. |
| 3 | Выделить `[M01]`–`[M06]`, Ctrl+C. | Все записи по порядку, разделены переводами строк; кириллица и эмодзи `✓` корректны. |
| 4 | Сузить колонку Message до 50 px, повторить копирование. | Текст полный, не обрезан многоточием. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
