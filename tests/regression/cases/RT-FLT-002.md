# RT-FLT-002. Exclude / Exclude All But из контекстного меню и комбинирование фильтров

## Цель

Проверить фильтры из контекстного меню и их сочетание.

## Проверяемые требования

- `REQ-FLT-02` — Контекстное меню ячейки индексируемого поля: Exclude и Exclude All But.
- `REQ-FLT-03` — Чипы фильтров над сеткой: `Поле: значение` для одного значения, `Поле: N hidden` для нескольких, удаление чипа (Remove filter) и Clear all filters.
- `REQ-FLT-04` — Фильтры по нескольким колонкам комбинируются (AND по колонкам).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `tab-basic.log`. Правый клик по ячейке `Component` = `Net` строки `[T01]` → `Exclude`. | Строки с Component `Net` скрыты (T01, T02, T03, T06, T12, T13). Чип `Component: Net`. |
| 2 | Правый клик по ячейке `Thread` = `0x0A02` (например `[T04]`) → `Exclude All But`. | Видны только строки потока `0x0A02` и не `Net`: T04, T05, T10, T11, T14. Два чипа: `Component: Net` и `Thread: 2 hidden`. |
| 3 | Нажать на крестик (`Remove filter`) у чипа `Component`. | Фильтр по Component снят, остаётся только фильтр по Thread (те же 5 строк, т.к. у 0x0A02 нет Net). |
| 4 | Правый клик в сетке → `Clear all filters` (или кнопка очистки у чипов). | Все 16 строк видны, чипов нет. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
