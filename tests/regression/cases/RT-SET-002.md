## Цель

Проверить горячую перезагрузку.

## Проверяемые требования

- `REQ-SET-02` — Ручное изменение `appsettings.yaml` подхватывается без перезапуска (цвета, форматы, обнаружение бинарных данных, маппинги, символы, профили, gutter Message).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `colors.log` и `hex.log`. В `%APP%\appsettings.yaml` в профиле Classic изменить цвет правила `\tWRN\t` на `Blue`, сохранить файл. | Через ≤ 2 с `[C02]` синий без перезапуска/переоткрытия. |
| 2 | Установить `DetectHex: false`, сохранить. Переключиться на вкладку `hex.log`, затем обратно на `colors.log` и снова на `hex.log`. | BIN у HEX-строк исчезает без перезапуска и переоткрытия, в том числе во вкладке, которая была неактивна при сохранении (#106). |
| 3 | Вернуть `DetectHex: true`, сохранить. | BIN появилась. |
| 4 | Изменить `SelectedProfile: Plain text`, сохранить. | Селектор профиля показывает `Plain text`, документы перечитаны в одну колонку (#115). |
| 5 | В YAML добавить копию профиля `Plain text` под именем `HotReload`, сохранить; открыть селектор профилей. | Профиль `HotReload` появился в селекторе без перезапуска; выбор применяет его к открытым документам. |
| 6 | Удалить профиль `HotReload` из YAML, сохранить. | Профиль исчез из селектора; если он был активен, выбран профиль из `SelectedProfile`, аварии нет. |
| 7 | Вернуть `Classic`, исходный цвет, сохранить. | Исходное состояние. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
