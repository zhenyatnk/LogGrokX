## Цель

Проверить горячую перезагрузку.

## Проверяемые требования

- `REQ-SET-02` — Ручное изменение `appsettings.yaml` подхватывается без перезапуска (цвета, форматы, обнаружение бинарных данных, маппинги, символы, профили).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `colors.log` и `hex.log`. В `%APP%\appsettings.yaml` в профиле Classic изменить цвет правила `\tWRN\t` на `Blue`, сохранить файл. | Через ≤ 2 с `[C02]` синий без перезапуска/переоткрытия. |
| 2 | Установить `DetectHex: false`, сохранить. | BIN у HEX-строк исчезает. |
| 3 | Вернуть `DetectHex: true`, сохранить. | BIN появилась. |
| 4 | Изменить `SelectedProfile: Plain text`, сохранить. | Селектор профиля показывает `Plain text`, документы перечитаны в одну колонку. |
| 5 | Вернуть `Classic`, исходный цвет, сохранить. | Исходное состояние. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
