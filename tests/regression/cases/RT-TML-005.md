## Цель

Проверить управление размещением таймлайна.

## Проверяемые требования

- `REQ-TML-05` — Положение таймлайна: View → Timeline (Timeline at top / At the bottom / Hidden), сохраняется (TimelineAtTop, TimelineVisible).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `threads.log`. View → Timeline → `At the bottom`. | Таймлайн под сеткой. |
| 2 | View → Timeline → `Hidden`. | Таймлайн скрыт, сетка занимает место. |
| 3 | Закрыть и запустить приложение, открыть файл. | Таймлайн скрыт (настройка сохранена: в `appsettings.yaml` `TimelineVisible: false`). |
| 4 | View → Timeline → `Timeline at top`. | Таймлайн сверху; в YAML `TimelineAtTop: true`, `TimelineVisible: true`. |
| 5 | Проверить кнопку-переключатель таймлайна (если есть в заголовке документа): подсказки `Timeline: top...`, `Timeline: bottom...`, `Timeline: off...`. | Цикл top → bottom → off → top соответствует подсказкам. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
