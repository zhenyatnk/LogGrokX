# RT-CLR-001. Правила цвета Classic: первое совпадение

| Поле | Значение |
|---|---|
| ID | `RT-CLR-001` |
| Область | CLR — Правила цвета |
| Приоритет | P1 |
| Тип | Функциональный |
| Требования | `REQ-CLR-01`, `REQ-CLR-02` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |
| Данные | `%RT%\testdata\colors.log` |
| Ориентировочная длительность | 5 мин |
| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Проверить правила цвета.

## Проверяемые требования

- `REQ-CLR-01` — Правила цвета профиля применяются к тексту строки; срабатывает первое подходящее правило; правило без цвета оставляет цвет по умолчанию.
- `REQ-CLR-02` — ForegroundColor и BackgroundColor (именованные цвета и `#AARRGGBB`) поддерживаются; правила видны в обеих темах.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `colors.log` (Classic, TAB). | Файл открыт, 11 строк `[C01]`–`[C11]`. |
| 2 | Проверить цвета `[C01]`–`[C04]`. | `[C01]` красный текст; `[C02]` Chocolate; `[C03]` серый; `[C04]` DarkRed. |
| 3 | Проверить `[C05]` (`FATAL`). | Фон `#FFCD5C5C` (IndianRed), текст по умолчанию. |
| 4 | Проверить `[C06]` (` error `). | Красный текст (правило `\Werror\W`). |
| 5 | Проверить `[C07]` (ERR, `No error here`). | Цвет по умолчанию: первое правило `No error` без цвета. |
| 6 | Проверить `[C08]` (`error: 0x0`). | Цвет по умолчанию: правило `error: 0x0` раньше `\Werror\W`. |
| 7 | Проверить `[C09]` (ERR + fatal). | Красный текст БЕЗ фона: сработало первое правило (ERR), правило fatal не применяется. |
| 8 | Проверить `[C10]`, `[C11]`. | Цвет по умолчанию. |
| 9 | Переключить тему Dark. | Цвета правил сохраняются, текст читаем. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
