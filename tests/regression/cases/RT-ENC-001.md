| Поле | Значение |
|---|---|

| Профиль | `Classic` |

## Цель

Проверить автоопределение кодировки.

## Проверяемые требования

- `REQ-ENC-01` — Определение кодировки: UTF-8 с BOM и без, UTF-16LE с BOM и без BOM, UTF-16BE с BOM.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `encoding\utf8-bom.log`. | 5 строк, `Кириллица и ümlaut №1…5` без «кракозябр», формат распознан (колонки Time/Level/Thread/Component/Message). |
| 2 | Открыть `encoding\utf8-nobom.log`. | Аналогично, текст корректен. |
| 3 | Открыть `encoding\utf16le-bom.log`. | Аналогично, текст корректен, нет символов `\0` между буквами. |
| 4 | Открыть `encoding\utf16le-nobom.log`. | Аналогично (распознавание UTF-16LE без BOM по CRLF). |
| 5 | Открыть `encoding\utf16be-bom.log`. | Аналогично. |
| 6 | Во всех пяти вкладках выполнить поиск `ümlaut №3`. | В каждой вкладке ровно 1 совпадение в строке `[E03]`. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
