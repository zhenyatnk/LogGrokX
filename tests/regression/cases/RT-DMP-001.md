## Цель

Проверить настройку дампов.

## Проверяемые требования

- `REQ-DMP-01` — Debug → Enable crash dumps / Max dumps count (положительное целое) настраивает WER LocalDumps для LogGrokX.exe (через UAC), отключение удаляет ключ; требуется перезапуск.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).
- Учётная запись с правами администратора (UAC).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Settings → Debug: включить `Enable crash dumps`, Max dumps count = `3`, Save. | Запрос UAC (повышение прав для `EnableWerOnly`); сообщение о необходимости перезапуска (`Restart required`). |
| 2 | Подтвердить UAC, проверить реестр: `reg query "HKLM\SOFTWARE\Microsoft\Windows\Windows Error Reporting\LocalDumps\LogGrokX.exe"`. | `DumpFolder` = `%LOCALAPPDATA%\LogGrokX\Dumps`, `DumpCount` = 3, `DumpType` = 2. |
| 3 | Max dumps count = `abc`. | `Max dumps count must be a positive integer.` |
| 4 | Выключить `Enable crash dumps`, Save, подтвердить UAC. | Ключ реестра `LogGrokX.exe` удалён. |
| 5 | Отклонить UAC при включении. | Приложение не падает, настройка не применена/сообщено об ошибке. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
