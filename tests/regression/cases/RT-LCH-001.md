## Цель

Убедиться, что приложение стартует в чистом окружении и показывает экран приветствия.

## Проверяемые требования

- `REQ-LCH-01` — Запуск без аргументов показывает главное окно с экраном приветствия (Explore your logs, Open log file, подсказка Ctrl+O / drag and drop).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Запустить `%APP%\LogGrokX.exe` без аргументов. | Открыто одно главное окно LogGrokX. В области документов показан экран приветствия: заголовок `Explore your logs`, текст `Open a log file or drag it into this window to search, filter and compare events.`, кнопка `Open log file`, подсказка `Ctrl+O to open a file · or drag and drop it here`. |
| 2 | Проверить заголовок окна (title bar). | Есть селектор профиля (выбран `Classic`) и кнопки `Open`, `View`, `Settings`, `Support` (`?`). Индикатор обновления отсутствует (UpdateMode: disabled). |
| 3 | Нажать кнопку `Open log file` на экране приветствия. | Открывается стандартный диалог выбора файлов Windows с фильтрами `All Files`, `Log files(*.log)`, `Text files(*.txt)`. |
| 4 | Нажать `Cancel` в диалоге. | Диалог закрыт, документ не открыт, экран приветствия остаётся, ошибок нет. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
