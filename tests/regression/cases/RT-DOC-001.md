## Цель

Проверить штатное открытие файлов.

## Проверяемые требования

- `REQ-DOC-01` — Открытие файлов через кнопку Open / Ctrl+O, мультивыбор в диалоге, фильтры диалога (All Files, Log files, Text files).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Нажать `Ctrl+O`. | Открывается диалог выбора файлов. |
| 2 | Перейти в `%RT%\testdata`, выделить `tab-basic.log`, `threads.log`, `colors.log` (Ctrl+клик), нажать `Open`. | Открыты три вкладки в порядке выбора, активна одна из них; у каждой корректное число строк (16, 18, 11). |
| 3 | Переключить фильтр диалога на `Text files(*.txt)` и перейти в `testdata\time`. | Видны только `*.txt` (например, `notime.txt`). |
| 4 | Нажать кнопку `Open` в заголовке окна. | Открывается тот же диалог (кнопка и Ctrl+O эквивалентны). |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
