# RT-PRF-002. Управление профилями: New, Copy, Remove, переименование

| Поле | Значение |
|---|---|
| ID | `RT-PRF-002` |
| Область | PRF — Профили конфигурации |
| Приоритет | P1 |
| Тип | Функциональный |
| Требования | `REQ-PRF-02`, `REQ-PRF-03` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |
| Данные | `%RT%\testdata\tab-basic.log` |
| Ориентировочная длительность | 5 мин |
| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Проверить управление профилями.

## Проверяемые требования

- `REQ-PRF-02` — Settings → Profiles: New, Copy (`{0} copy`), Remove (остаётся минимум один), уникальные непустые имена.
- `REQ-PRF-03` — Смена форматов/цветов перечитывает открытые логи с сохранением меток; переименование без изменения конфигурации не перечитывает.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Settings → Profiles: выбрать `Classic`, `Copy`. | Профиль `Classic copy` с теми же форматами и цветами. |
| 2 | Переименовать `Classic copy` в `RT Copy`, Save, открыть `tab-basic.log` с меткой `[T03]`, засечь время. | Профиль `RT Copy` активен; т.к. конфигурация не изменилась относительно ранее применённой — файл не перечитывается (нет индикатора загрузки). |
| 3 | В `RT Copy` удалить правило `\tWRN\t`, Save. | Файл перечитан, `[T04]` без цвета, метка `[T03]` сохранена. |
| 4 | `New` — пустое имя, Save. | `Every profile must have a name.` (или предложение автоисправления `A profile without a name will be named …`). |
| 5 | Имя `Classic`. | `Profile names must be unique.` |
| 6 | Удалить все профили кроме одного; попытаться удалить последний. | `Remove` недоступна для последнего профиля. |
| 7 | Cancel. | Изменения не сохранены. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Удалить `RT Copy`, выбрать `Classic`.
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
