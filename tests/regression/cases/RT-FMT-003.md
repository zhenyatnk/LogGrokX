| Поле | Значение |

## Цель

Проверить порог доли совпадений при автоопределении.

## Проверяемые требования

- `REQ-FMT-02` — Автоопределение формата по первым строкам файла (до 256 строк / 1 МБ): выбирается формат с наибольшей долей совпадений.
- `REQ-FMT-03` — Порог автоопределения: доля совпадений должна быть больше 5%, иначе файл открывается как текст (вся строка — одно поле).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `formats\below-threshold.log` (3 подходящие строки из 97 ≈ 3%). | Формат НЕ выбран: файл открыт в текстовом режиме — одна колонка с полным текстом строки, нет колонок Level/Thread/Component, 97 строк. |
| 2 | Открыть `formats\above-threshold.log` (10 из 100 = 10%). | Выбран формат 1 Classic: колонки Time/Level/Thread/Component/Message; строки `noise line N` присоединены к предыдущим записям как продолжение; число записей = 10. |
| 3 | В `above-threshold.log` выполнить поиск `noise line 15`. | 1 совпадение внутри записи `[F91] formatted 10`. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
