## Цель

Регрессия #97: правила выделения при Alt+клике.

## Проверяемые требования

- `REQ-ALT-03` — Пары `key = value` / `key: value`: курсор на ключе/разделителе выделяет пару, на значении — только значение; фигурные скобки сохраняются.
- `REQ-ALT-04` — Кавычки, пути Windows (`\\?\Volume{GUID}\`, `\Device\HarddiskVolume1\`), скобки `[] <> ()` (содержимое без скобок, с вложенностью), апостроф внутри слова.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Строка `[S01]`: Alt+клик по ключу `user` (в `user = alice`). | Добавлено `user = alice` целиком (с пробелами). |
| 2 | Очистить. Alt+клик по значению `alice`. | Добавлено только `alice`. |
| 3 | Очистить. Alt+клик по `path` в `path: C:\temp\data`. | Добавлено `path: C:\temp\data` (в regex экранировано). |
| 4 | Строка `[S02]`: Alt+клик по `code` (`code : 404`), затем отдельно по `key` (`key\t=\tvalue-tab`). | `code : 404` целиком; для `key<TAB>=<TAB>value-tab` ожидается пара целиком (табуляция как пробельный разделитель) — фактическое поведение зафиксировать в отчёте. |
| 5 | Строка `[S03]`: Alt+клик по `John`. | Добавлено `"John Smith"` вместе с кавычками. |
| 6 | Строка `[S04]`: Alt+клик по `Volume`. | Добавлен путь `\\?\Volume{3F2504E0-4F89-11D3-9A0C-0305E82C3301}\` целиком (с завершающим `\`); и отдельно `\Device\HarddiskVolume1\`. |
| 7 | Строка `[S05]`: Alt+клик по `[` внешней скобки. | Добавлено содержимое `outer [inner] tail` без внешних скобок. |
| 8 | Строка `[S05]`: Alt+клик по `<` и по `(`. | `a<b>c` и `x(y)z` соответственно. |
| 9 | Строка `[S06]`: Alt+клик по `Can't`. | Добавлено `Can't` (апостроф не открывает кавычки). |
| 10 | Строка `[S07]`: Alt+клик по `requestor`, затем по `{unknown}`. | `requestor={unknown}` и `{unknown}`. |
| 11 | Для каждого шага проверить, что найдено ≥ 1 совпадение в исходной строке. | Все сформированные шаблоны находят исходную строку. |
