# RT-ENC-005. Unicode разных письменностей: font fallback и общая базовая линия

| Поле | Значение |
|---|---|
| ID | `RT-ENC-005` |
| Область | ENC — Кодировки и окончания строк |
| Приоритет | P1 |
| Тип | Регрессия дефекта |
| Требования | `REQ-ENC-06` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |
| Данные | `%RT%\testdata\unicode.log` |
| Ориентировочная длительность | 5 мин |
| Дефекты (регрессия) | [#108](https://github.com/zhenyatnk/LogGrokX/issues/108) |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Регрессия #108: японский текст отображался квадратами; проверка посимвольного font fallback и общей базовой линии GlyphRun (PR #145, #148, #149).

## Проверяемые требования

- `REQ-ENC-06` — Текст любых письменностей (CJK, корейский, греческий, деванагари, символы) отображается через посимвольный font fallback без квадратов; фрагменты разных шрифтов в одной строке стоят на общей базовой линии, высота строки учитывает метрики всех шрифтов (#108).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `unicode.log`. | 8 записей `[U01]`…`[U08]`. Японский, китайский, корейский, греческий, деванагари, математические символы, стрелки, псевдографика и `✓✗` отображаются символами, а не квадратами или `?` (#108). |
| 2 | Сравнить высоту строк `[U01]` (только латиница) и `[U02]`–`[U08]`. | Высота всех строк одинакова, соседние строки не перекрываются, нижние выносные элементы `g`, `p` не обрезаны. |
| 3 | Увеличить масштаб снимка до 400% и сравнить `Hxgp` в `[U01]` и `[U08]` (латиница чередуется с CJK). | Латинские буквы в `[U08]` стоят на одной базовой линии с CJK-фрагментами и на той же высоте, что в `[U01]`; текст не «прыгает» вверх-вниз при смене шрифта (PR #149). |
| 4 | Масштаб текста `Ctrl+=` до 200%, затем `Ctrl+0`. | Fallback-символы и базовая линия сохраняются на всех масштабах; высота строки пересчитывается без наложений. |
| 5 | Искать `日本語` (обычный текст), затем Alt+клик по `한국어` в `[U08]`. | Поиск находит `[U02]`, `[U08]`; подсветка совпадает с границами иероглифов. Alt+клик добавляет непрерывный фрагмент без разрыва суррогатов и лишних символов. |
| 6 | Пометить `[U08]` и выделить её, `Ctrl+C`, `Get-Clipboard`. | В Marked lines текст отображается так же, как в сетке; в буфере исходная строка без замены символов. |
| 7 | Переключить тему на Dark. | Все символы читаемы, fallback-шрифты получают цвет текста темы. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Краевые случаи и примечания

- Нужны шрифты Windows по умолчанию (Yu Gothic / Meiryo, Microsoft YaHei, Malgun Gothic, Nirmala UI). Если на стенде урезан набор шрифтов, указать это в отчёте; квадраты при отсутствии любого подходящего шрифта — не дефект.
- Эмодзи в данные не включены намеренно: их вид в WPF зависит от набора шрифтов и не относится к проверяемому дефекту.
