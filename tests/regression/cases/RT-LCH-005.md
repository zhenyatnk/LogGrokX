# RT-LCH-005. Единственный экземпляр: передача путей в запущенное окно

| Поле | Значение |
|---|---|
| ID | `RT-LCH-005` |
| Область | LCH — Запуск и единственный экземпляр |
| Приоритет | P1 |
| Тип | Функциональный |
| Требования | `REQ-LCH-05`, `REQ-LCH-08`, `REQ-DOC-03` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |
| Данные | `%RT%\testdata\tab-basic.log` |
| Ориентировочная длительность | 5 мин |
| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Проверить механизм единственного экземпляра (mutex + named pipe).

## Проверяемые требования

- `REQ-LCH-05` — Единственный экземпляр: повторный запуск с путями передаёт их в уже запущенное окно.
- `REQ-LCH-08` — Повторный запуск без аргументов не открывает второе окно и не влияет на первое.
- `REQ-DOC-03` — Повторное открытие уже открытого файла (сравнение полного пути без учёта регистра) активирует существующую вкладку.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Запустить LogGrokX без аргументов, дождаться окна. | Одно окно, экран приветствия. |
| 2 | Не закрывая окно, выполнить `& "%APP%\LogGrokX.exe" "%RT%\testdata\tab-basic.log"`. | Второй процесс быстро завершается (`Get-Process LogGrokX` — один процесс). В первом окне появилась вкладка `tab-basic.log`. |
| 3 | Выполнить ту же команду, но путь указать в другом регистре: `...\TESTDATA\TAB-BASIC.LOG`. | Новая вкладка не создаётся, активируется существующая `tab-basic.log`. |
| 4 | Выполнить `& "%APP%\LogGrokX.exe"` без аргументов. | Второе окно не появляется, первое окно и его вкладки не изменились, процесс один. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
