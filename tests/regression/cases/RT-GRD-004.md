## Цель

Проверить скрытие/показ столбцов (#135).

## Проверяемые требования

- `REQ-GRD-06` — Столбцы полей можно скрывать и показывать через контекстное меню заголовка (`Columns` / `Hide column` / `Show all columns`); скрытый столбец возвращается на прежнее место, а индексация и фильтры по значениям продолжают работать (#135).
- `REQ-GRD-01` — Ctrl+C / Copy копирует выделенные строки полностью (без многоточий) в исходном виде (#33).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `classic-multiline.log`. Правой кнопкой по заголовку столбца `Time`. | Меню содержит `Hide column`, подменю `Columns` с отмеченными пунктами `Time`, `Level`, `Thread`, `Component`, `Message` и `Show all columns` (недоступен). |
| 2 | `Columns` → снять `Component`. | Столбец `Component` скрыт, порядок остальных сохранён; подменю остаётся открытым. |
| 3 | В том же подменю снять `Time`, закрыть меню. | Скрыты `Component` и `Time`; прокрутка и копирование строк работают; аварий нет. |
| 4 | Снова открыть `Columns` → отметить `Component`. | Столбец `Component` появился на прежнем месте (между `Thread` и `Message`). |
| 5 | `Show all columns`. | Видны все столбцы полей, `Show all columns` недоступен. |
| 6 | Правой кнопкой по заголовку первого (номер строки) столбца. | Пункт `Hide column` отсутствует, номер строки скрыть нельзя. |
| 7 | Скрыть `Thread`, затем нажать кнопку-воронку в заголовке `Component` и выбрать значение. | Список значений строится по исходным данным при скрытом `Thread`; фильтр применяется и копирование работает. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Вернуть все столбцы через `Show all columns`.
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
