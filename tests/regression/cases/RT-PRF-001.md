# RT-PRF-001. Переключение профилей и сохранение меток

| Поле | Значение |
|---|---|
| ID | `RT-PRF-001` |
| Область | PRF — Профили конфигурации |
| Приоритет | P1 |
| Тип | Функциональный |
| Требования | `REQ-PRF-01`, `REQ-PRF-03` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |
| Данные | `%RT%\testdata\tab-basic.log`<br>`%RT%\testdata\formats\venn.log`<br>`%RT%\testdata\colors.log` |

## Цель

Проверить переключение профилей.

## Проверяемые требования

- `REQ-PRF-01` — Селектор профиля в заголовке: переключение сразу применяется ко всем открытым документам и сохраняется (SelectedProfile).
- `REQ-PRF-03` — Смена форматов/цветов перечитывает открытые логи с сохранением меток; переименование без изменения конфигурации не перечитывает.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `tab-basic.log` и `formats\venn.log`, пометить `[T05]`. | Classic активен. |
| 2 | Селектор профиля в заголовке → `Plain text`. | Оба документа сразу перечитаны: одна колонка `Text`, цветов нет; метка `[T05]` сохранена. |
| 3 | → `Venn`, перейти на вкладку `venn.log`. | `venn.log` полностью разобран форматом Venn: все 5 строк `[V01]`–`[V05]`, прогресс загрузки завершён (не застрял на 40%), цвета `[CRIT]`/`[ERRO]` (#113). В логе `%LOGS%` нет `ArgumentOutOfRangeException` из `IndexKey.GetHashCode`. |
| 4 | Повторить цепочку `Classic` → `Plain text` → `Venn` → `Classic` ещё 2 раза без переоткрытия файлов. | Каждый раз оба документа перечитываются полностью, `tab-basic.log` — 16 строк в Classic; метка `[T05]` сохранена. |
| 5 | → `Classic`, перезапуск. | Профиль `Classic` восстановлен (SelectedProfile). |
| 6 | Открыть новый файл `colors.log`. | Разобран активным профилем. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
