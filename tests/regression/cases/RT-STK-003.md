## Цель

Проверить показ исходников.

## Проверяемые требования

- `REQ-STK-03` — Окно Show call stack: кадры (модуль, функция, исходник), Copy call stack, Reload symbols, просмотр исходника с подсветкой строки, Open in editor; следует теме и акценту.
- `REQ-STK-05` — Settings → Symbols: Resolve call stacks in log messages, Symbol path (по строке на элемент), Source path, Symbol cache folder, Allow source server commands; применяется без перезапуска (#89).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Подготовить собственную сборку DLL с PDB и исходником (например, сборку LogGrokX `Debug` с нативной зависимостью) или пропустить при отсутствии — BLOCKED. | Есть DLL+PDB+исходники. |
| 2 | Указать Symbol path = папка с PDB, Source path = папка исходников. Сформировать кадр `0# module.dll!RVA` по известной функции. | Кадр разрешён с `[file @ line]`. |
| 3 | Show call stack → выбрать кадр. | Исходник загружен при выборе (не при открытии окна), строка подсвечена и центрирована; C/C++ подсветка синтаксиса; `Open in editor` открывает файл. |
| 4 | Проверить флажок `Allow source server commands` выключен по умолчанию. | Командные источники (tf.exe, git) не выполняются. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
