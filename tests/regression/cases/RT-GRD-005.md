## Цель

Регресс порядка столбцов при частичном восстановлении (#135).

## Проверяемые требования

- `REQ-GRD-07` — Если при показе столбца часть столбцов с меньшим исходным индексом остаётся скрытой, столбец вставляется на своё место относительно видимых (перед столбцами с большим исходным индексом), а не в конец (#135).
- `REQ-GRD-06` — Столбцы полей можно скрывать и показывать через контекстное меню заголовка (`Columns` / `Hide column` / `Show all columns`); скрытый столбец возвращается на прежнее место, а индексация и фильтры по значениям продолжают работать (#135).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `biglines.log` (Classic). Правой кнопкой по заголовку `Thread`. | Столбцы полей: `Time`, `Level`, `Thread`, `Component`, `Message`. |
| 2 | `Columns` → снять `Component`. | `Component` скрыт; видно `Time`, `Level`, `Thread`, `Message`. |
| 3 | `Columns` → снять `Thread`. | `Thread` скрыт; видно `Time`, `Level`, `Message`. |
| 4 | `Columns` → отметить `Component`. | `Component` вставлен между `Level` и `Message` (перед `Message`), а НЕ в конец после `Message`. |
| 5 | `Columns` → отметить `Thread`. | `Thread` вставлен между `Level` и `Component`; порядок снова `Time`, `Level`, `Thread`, `Component`, `Message`. |
| 6 | `Show all columns`, затем закрыть и снова открыть файл (или пересоздать документ). | Порядок столбцов остаётся исходным, скрытых нет. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Вернуть все столбцы через `Show all columns`.
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
