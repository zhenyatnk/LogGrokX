# RT-MRK-003. Повторная пометка и Clear all в открытом документе: память освобождается

| Поле | Значение |
|---|---|
| ID | `RT-MRK-003` |
| Область | MRK — Помеченные строки |
| Приоритет | P3 |
| Тип | Нефункциональный |
| Требования | `REQ-MRK-05` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |
| Данные | `%RT%\testdata\many-matches.log` |
| Ориентировочная длительность | 15 мин |
| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Проверить, что снятые метки не удерживаются документом: раньше модели меток были подписаны на `ColorSettings` открытого документа и не освобождались (PR #147).

## Проверяемые требования

- `REQ-MRK-05` — Снятые метки (Space, Toggle marks, Clear all) освобождаются при открытом документе: повторные циклы пометки и очистки не увеличивают память процесса.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `many-matches.log` (5000 строк). Записать `Get-Process LogGrokX \| select WS, PrivateMemorySize64` как исходное значение `M0`. | Документ открыт, значения записаны в `metrics`. |
| 2 | Кликнуть в сетку, `Ctrl+A`, `Space`. | Все 5000 строк помечены; в Marked lines группа `many-matches.log` с 5000 строк; UI отвечает, задержка ≤ 5 с. |
| 3 | Прокрутить Marked lines до конца и обратно, затем в группе нажать `Clear all`. | Метки сняты со всех строк, группа исчезла из Marked lines, цвета строк в сетке не изменились. |
| 4 | Повторить шаги 2–3 ещё 4 раза (всего 5 циклов). После каждого цикла подождать 10 с и записать `PrivateMemorySize64` (`M1`…`M5`). | Аварий и зависаний нет. Память не растёт линейно с числом циклов: `M5 − M1` не больше 20% от `M1 − M0` и не больше 50 МБ. |
| 5 | Переключить тему на Dark и обратно на Light, добавить в Classic любое правило цвета через Settings, Save; снова пометить 3 строки. | Смена цветовых настроек документа после циклов Clear all не вызывает исключений; новые метки отображаются с актуальными цветами. |
| 6 | Удалить добавленное правило, Save. | Исходное состояние. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Краевые случаи и примечания

- Замер памяти ориентировочный: GC может не сработать между циклами. При росте сверх порога повторить цикл ещё 2 раза и зафиксировать тренд; дефект заводить только при устойчивом росте.
- Если `Ctrl+A` + `Space` на 5000 строках недоступно, пометить диапазон Shift+клик по 1000 строк и указать это в отчёте.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Вернуть светлую тему и исходные правила цвета.
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
