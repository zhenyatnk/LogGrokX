## Цель

Проверить работу меток.

## Проверяемые требования

- `REQ-MRK-01` — Пометка строк булавкой и клавишей Space (переключение для выделения: если есть непомеченные — помечаются все).
- `REQ-MRK-02` — Панель Marked lines: группы по файлам, Clear all для группы, Copy lines; навигация стрелками без Enter; переход центрирует строку.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `tab-basic.log`. Клик по булавке строки `[T02]`. | Строка помечена; в панели `Marked lines` группа `tab-basic.log` с `[T02]`. |
| 2 | Выделить `[T04]` и нажать `Space`. | `[T04]` помечена. |
| 3 | Выделить `[T02]`–`[T05]` (Shift), `Space`. | Есть непомеченные → помечены все 4 (`T02`–`T05`). |
| 4 | Снова `Space` на том же выделении. | Все помечены → метки сняты со всех 4. |
| 5 | Контекстное меню → `Toggle marks` на `[T07]`. | `[T07]` помечена. |
| 6 | Пометить `[T01]`, `[T10]`, `[T16]`; в Marked lines нажать стрелку Down/Up. | Сетка следует за текущей меткой без Enter, строка центрируется. |
| 7 | `Copy lines` в группе Marked lines; `Get-Clipboard`. | Скопированы помеченные строки по порядку. |
| 8 | Открыть `threads.log`, пометить `[G01]`. В Marked lines у группы `tab-basic.log` нажать `Clear all`. | Сняты метки только `tab-basic.log`; метка `[G01]` осталась; во время очистки сетка не прыгает по строкам. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
