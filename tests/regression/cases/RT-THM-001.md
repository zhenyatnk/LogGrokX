## Цель

Проверить темы.

## Проверяемые требования

- `REQ-THM-01` — View → Theme → Light/Dark (и переключатель в заголовке) применяются ко всему приложению сразу и сохраняются в `Theme.json`.
- `REQ-THM-02` — Accent color: Blue, Purple, Pink, Red, Orange, Green, Teal — применяется сразу и сохраняется.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | View → Theme → Dark. | Всё приложение тёмное сразу (сетка, заголовки, панели, окна Settings/Support/Saved searches). |
| 2 | Перезапустить. | Тёмная тема восстановлена без вспышки светлой (иконки заголовка корректного цвета на первом кадре); `%LOCALAPPDATA%\LogGrokX\Data\Theme.json` обновлён. |
| 3 | Кнопка `Toggle light / dark theme`. | Светлая тема. |
| 4 | Settings → View → Accent color: по очереди Blue, Purple, Pink, Red, Orange, Green, Teal, Save. | Акцент (выделение, ссылки, кнопки) меняется сразу; после перезапуска сохраняется. |
| 5 | Вернуть Blue и Light. | Исходное состояние. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
