# RT-THR-001. Группировка по потокам и разделители

| Поле | Значение |
|---|---|
| ID | `RT-THR-001` |
| Область | THR — Группировка по потокам |
| Приоритет | P1 |
| Тип | Функциональный |
| Требования | `REQ-THR-01`, `REQ-THR-02` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |
| Данные | `%RT%\testdata\threads.log` |
| Ориентировочная длительность | 5 мин |
| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Проверить группировку по потокам.

## Проверяемые требования

- `REQ-THR-01` — Group by thread (View) объединяет подряд идущие строки одного Thread, приглушает повтор Thread и рисует разделители; настройка сохраняется (GroupByThread).
- `REQ-THR-02` — Show thread group separators (Settings → View) скрывает/показывает разделители, приглушение сохраняется.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `threads.log`. View → `Group by thread` включить. | 8 групп: `G01–G03` (0x0B01), `G04–G05` (0x0B02), `G06` (0x0B01), `G07–G10` (0x0B03), `G11–G13` (0x0B02), `G14–G15` (0x0B01), `G16` (0x0B03), `G17–G18` (0x0B02); значение Thread приглушено в строках-продолжениях группы; между группами разделители. |
| 2 | Settings → View → `Show thread group separators` выключить, Save. | Разделители скрыты, приглушение Thread осталось. |
| 3 | Включить обратно, Save. | Разделители видны. |
| 4 | Исключить фильтром Thread `0x0B02`. | Группы пересчитаны по видимым строкам: `G01–G03`+`G06` объединяются в одну группу 0x0B01 и т.д. |
| 5 | Перезапустить приложение. | Группировка включена (GroupByThread сохранён). |
| 6 | Выключить группировку. | Обычное отображение. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Выключить Group by thread.
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
