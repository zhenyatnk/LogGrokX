## Цель

Проверить окно управления сохранёнными поисками.

## Проверяемые требования

- `REQ-SAV-03` — Окно Manage saved searches…: фильтр, создание (Ctrl+N), дублирование, удаление (Delete) с отложенным удалением и Restore search, Save (Ctrl+S), Cancel.
- `REQ-SAV-04` — Валидация: пустой шаблон (`Enter a search query.`), невалидный regex; подтверждение `Discard unsaved changes?` при переключении.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `Manage saved searches…`. | Окно `Saved searches` со списком, полем `Filter saved searches...`, кнопками New search/Duplicate/Delete, `Save`, `Cancel`. |
| 2 | Нажать `Ctrl+N`, оставить шаблон пустым, ввести имя `RT empty`. | Сообщение `Enter a search query.`; `Save` недоступна. |
| 3 | Ввести шаблон `alpha`, нажать `Ctrl+S`. | Поиск `RT empty` сохранён и появился в списке. |
| 4 | Выбрать `RT empty`, нажать `Duplicate`. | Появилась копия с суффиксом `copy`. |
| 5 | Выбрать копию, нажать `Delete` (клавишу). | Элемент помечен `Will be deleted when you save.`, кнопка меняется на `Restore search`; фокус остаётся в списке (#95). |
| 6 | Нажать `Restore search`, затем снова `Delete` и `Save`. | Копия удалена из списка после сохранения. |
| 7 | Изменить шаблон у `RT empty` и, не сохраняя, выбрать другой элемент. | Запрос `Discard unsaved changes?`; при отказе остаёмся на редактируемом элементе. |
| 8 | Ввести в фильтр `zzz-none`. | Текст `No saved searches found.` |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
