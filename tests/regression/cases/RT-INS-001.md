# RT-INS-001. Установка, обновление поверх и удаление

| Поле | Значение |
|---|---|
| ID | `RT-INS-001` |
| Область | INS — Установщик |
| Приоритет | P2 |
| Тип | Функциональный |
| Требования | `REQ-INS-01`, `REQ-INS-02` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |
| Данные | — |
| Ориентировочная длительность | 20 мин |
| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Да — при недоступности ресурса статус `BLOCKED` |

## Цель

Проверить установщик.

## Проверяемые требования

- `REQ-INS-01` — Установщик: выбор языка (8 языков), для пользователя/для всех, ярлык на рабочем столе, ассоциация `.log`, Install updates automatically.
- `REQ-INS-02` — Обновление установкой поверх сохраняет `appsettings.yaml`; удаление оставляет `appsettings.yaml` и удаляет ассоциацию.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).
- Виртуальная машина или чистая учётная запись Windows.

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Запустить `LogGrokX-<ver>-x64-setup.exe`; выбрать язык Русский. | Мастер на русском; задачи: ярлык на рабочем столе (по умолчанию выкл.), `Связать с файлами .log` (вкл.), `Устанавливать обновления автоматически`. |
| 2 | Установить для текущего пользователя с ассоциацией. | Установлено в `%LOCALAPPDATA%\Programs\LogGrokX` (или выбранную папку); есть `unins000.exe`; двойной клик по `.log` открывает LogGrokX; язык интерфейса — русский; `UpdateMode: install`. |
| 3 | Изменить `appsettings.yaml` (LogFontSize 15), установить ту же/новую версию поверх. | `appsettings.yaml` не перезаписан (LogFontSize 15). |
| 4 | Установить для всех пользователей (Program Files). | Запрос UAC, установка успешна. |
| 5 | Удалить через `Параметры → Приложения`. | Файлы удалены, ассоциация `.log` удалена, `appsettings.yaml` остался. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта
