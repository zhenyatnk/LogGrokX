## Цель

Проверить массовые операции.

## Проверяемые требования

- `REQ-GRD-02` — Копирование более 64 000 000 символов предлагает сохранить выделение в файл (Save selection, `selection.txt`).
- `REQ-GRD-03` — Массовые операции (копирование, метки) дольше 1 с показывают карточку прогресса с отменой (Esc/Cancel); UI остаётся отзывчивым.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | `pwsh %RT%\tools\New-LargeLog.ps1 -Path $env:TEMP\lgx-big.log -SizeMB 200`. Открыть файл, дождаться загрузки. | Файл открыт; строки `[L-FIRST]`…`[L-LAST]`. |
| 2 | `Ctrl+A`, `Ctrl+C`. | Через ~1 с появляется карточка прогресса с кнопкой Cancel; UI отзывчив. |
| 3 | Дождаться завершения. | Объём > 64 000 000 символов: диалог `Save selection` с именем по умолчанию `selection.txt`. |
| 4 | Сохранить в `%TEMP%\lgx-selection.txt`. | Файл создан; первая строка `[L-FIRST]`, последняя `[L-LAST]`; размер ≈ исходному. |
| 5 | Повторить `Ctrl+A`, `Ctrl+C` и нажать `Esc` во время прогресса. | Операция отменена, буфер не изменён, приложение работает. |
| 6 | Открыть `many-matches.log`, `Ctrl+A`, Space. | 5000 строк помечены; прогресс-карточка не показывается для быстрой операции (< 1 с) либо исчезает сразу. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Удалить `%TEMP%\lgx-big.log`, `%TEMP%\lgx-selection.txt`.
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
