## Цель

Проверить пользовательские форматы и явное поле времени.

## Проверяемые требования

- `REQ-FMT-01` — Формат лога описывается регулярным выражением с именованными группами; поля становятся колонками.
- `REQ-FMT-08` — TimeField/TimeFormat: явное поле времени (без учёта регистра) и формат времени; по умолчанию поле `Time` без учёта регистра (#109).
- `REQ-FMT-06` — Синтаксис групп `(?<Name>…)` и `(?'Name'…)` поддерживается одинаково.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).
- Активный профиль: `Regression`.

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Выбрать в заголовке профиль `Regression`. Открыть `formats\regression-a.log`. | Колонки Time/Level/Thread/Component/Message; Thread `T-1`, Component `Api`, Message `[RA01] regression format A`. |
| 2 | Открыть `formats\regression-b.log`. | Формат RegB: колонки `time`, `Severity`, `thread`, `component`, `Message` (регистр имён как в regex); значения `Info`, `worker-0`, `svc.api`. |
| 3 | Навести курсор на таймлайн документа `regression-b.log`. | Показывается время (`10:00:0x.xxx`), т.е. явное `TimeField: time` с форматом `yyyy-MM-ddTHH:mm:ss.fff` работает. |
| 4 | Открыть `formats\regression-n.log`. | Колонки Time/Level/Message, колонки Component нет. |
| 5 | В YAML (копия конфигурации) в формате RegB изменить `TimeField: time` на `TimeField: Time` и сохранить файл; переоткрыть `regression-b.log`. | Время по-прежнему распознано (TimeField сопоставляется без учёта регистра): таймлайн показывает даты (`10:00:0x.xxx`). Вернуть значение. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Краевые случаи и примечания

- Явное поле времени (`TimeField`) сопоставляется без учёта регистра, как и поле `Time` по умолчанию (#109).
