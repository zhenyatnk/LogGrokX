## Цель

Проверить масштабирование текста.

## Проверяемые требования

- `REQ-ZM-01` — Масштаб текста: Ctrl+= / Ctrl+Shift+= увеличивают, Ctrl+- уменьшает, Ctrl+0 сбрасывает к 12, Ctrl+колесо; диапазон 6–48.
- `REQ-ZM-02` — Меню View → Text size (Decrease/Reset/Increase) и значение LogFontSize сохраняется между запусками.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `tab-basic.log`. Нажать `Ctrl+0`. | Размер шрифта лога 12 (по умолчанию). |
| 2 | `Ctrl+=` ×3. | Размер 15; текст сетки, результатов поиска и Marked lines увеличен. |
| 3 | `Ctrl+Shift+=` ×1. | Размер 16. |
| 4 | `Ctrl+-` ×20. | Размер не меньше 6 (остановка на минимуме). |
| 5 | `Ctrl+=` ×60. | Размер не больше 48. |
| 6 | Ctrl+колесо вниз 3 щелчка. | Размер уменьшился на 3. |
| 7 | View → Text size → `Reset text size (Ctrl+0)`. | 12. |
| 8 | Установить 14 через `Increase`, перезапустить приложение. | Размер 14 сохранён (`LogFontSize: 14` в YAML). |
| 9 | Settings → View → `Log font size` показывает 14. | Значение совпадает. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
