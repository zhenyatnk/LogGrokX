## Цель

Регрессия #122: файл нулевой длины отображался как одна пустая запись и одна строка таймлайна.

## Проверяемые требования

- `REQ-ENC-05` — Пустой файл (0 байт) показывает страницу «This file is empty» вместо пустой записи и строки таймлайна; для непустых файлов страница не появляется (#122).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `encoding\empty.log` (0 байт). | Вкладка `empty.log` открыта. Вместо сетки показана страница: иконка документа, заголовок `This file is empty`, описание `The opened log file contains no data.` и кнопка `Open log file`. Пустой строки-записи (индекс 0) и отметки на таймлайне нет. |
| 2 | Проверить под страницей сетку, панель поиска и таймлайн. | Сетка и панель поиска закрыты страницей; таймлайн пуст или скрыт, подсказки с номером строки нет, исключений нет. |
| 3 | Нажать кнопку `Open log file`, затем `Cancel` в диалоге. | Открывается стандартный диалог выбора файлов; после отмены страница `This file is empty` остаётся. |
| 4 | Открыть `encoding\only-newlines.log` (непустой файл, 10 × CRLF). | Страница `This file is empty` не показывается: файл не пуст, отображается обычная сетка с пустыми строками (или 0 записей), без ошибок. |
| 5 | В той же сессии открыть `tab-basic.log`. | Обычная сетка: 16 строк `[T01]`…`[T16]`; страница пустого файла отсутствует. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
