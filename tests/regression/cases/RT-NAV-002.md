## Цель

Проверить клавиатуру в сетке.

## Проверяемые требования

- `REQ-NAV-03` — Клавиши Up/Down/PageUp/PageDown, Shift+Up/Down (расширение выделения), Ctrl+A.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `many-matches.log`, кликнуть строку `bulk-match 00010`. | Строка текущая. |
| 2 | `Down` ×3, `Up` ×1. | Текущая `00012`. |
| 3 | `PageDown`, затем `PageUp`. | Сдвиг на высоту экрана вниз и обратно к `00012` (±1). |
| 4 | `Shift+Down` ×4. | Выделено 5 строк `00012`–`00016`. |
| 5 | `Ctrl+C`, `Get-Clipboard`. | 5 строк. |
| 6 | `Ctrl+A`, `Ctrl+C`. | Скопировано 5000 строк (прогресс-карточка, если > 1 с). |
| 7 | Нажать `Up` на первой строке и `Down` на последней. | Без ошибок, курсор остаётся на границе. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.
