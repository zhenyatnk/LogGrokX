# RT-FLT-001. Всплывающее окно фильтра колонки

| Поле | Значение |
|---|---|
| ID | `RT-FLT-001` |
| Область | FLT — Фильтрация |
| Приоритет | P1 |
| Тип | Функциональный |
| Требования | `REQ-FLT-01`, `REQ-FLT-03`, `REQ-FLT-07` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |
| Данные | `%RT%\testdata\tab-basic.log` |
| Ориентировочная длительность | 5 мин |
| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Проверить фильтрацию через окно значений.

## Проверяемые требования

- `REQ-FLT-01` — Фильтр значений колонки через всплывающее окно: флажки значений, Select All, Deselect All, поиск Search..., Search Results Only.
- `REQ-FLT-03` — Чипы фильтров над сеткой: `Поле: значение` для одного значения, `Поле: N hidden` для нескольких, удаление чипа (Remove filter) и Clear all filters.
- `REQ-FLT-07` — Esc закрывает всплывающее окно фильтра.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `tab-basic.log`. Нажать кнопку фильтра в заголовке `Severity`. | Открыто окно со списком значений с флажками: `INF`, `DBG`, `WRN`, `ERR`, `IMP` (все отмечены), кнопки `Select All`, `Deselect All`, `Search Results Only`, поле `Search...`. |
| 2 | Снять флажок `INF`. | Сразу скрыты все строки INF (остаются T03, T04, T05, T07, T10, T12, T16 = 7 строк). Над сеткой чип `Severity: INF`. |
| 3 | Снять ещё `DBG`. | Остаются T04, T05, T07, T10, T12 (5 строк). Чип `Severity: 2 hidden`. |
| 4 | Нажать `Esc`. | Окно фильтра закрыто, фильтр остался. |
| 5 | Открыть фильтр снова, ввести в `Search...` `R`, нажать `Search Results Only`. | Отмечены только значения, содержащие `R` (`ERR`, `WRN`), остальные исключены: видны T04, T05, T10, T12. Чип `Severity: 3 hidden`. |
| 6 | Нажать `Select All`. | Все строки видны, чипа `Severity` нет. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
