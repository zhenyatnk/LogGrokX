# RT-JSN-006. Фиксированный folding gutter в Message и Marked lines

| Поле | Значение |
|---|---|
| ID | `RT-JSN-006` |
| Область | JSN — JSON/XML: форматирование и сворачивание |
| Приоритет | P1 |

| Требования | `REQ-JSN-09` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |

| Ориентировочная длительность | 5 мин |
| Дефекты (регрессия) | — |

## Цель

Проверить выравнивание текста и отключение фиксированного gutter.

## Проверяемые требования

- `REQ-JSN-09` — UseMessageFoldingGutter по умолчанию резервирует фиксированный gutter для всех строк Message и текста Marked lines; другие колонки сохраняют отступ только у folding-строк; false восстанавливает прежнее поведение везде.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `json-xml.log`. Сравнить `[J03]` (обычный текст) и `[J01]` (свёрнутый JSON). | `UseMessageFoldingGutter` включён по умолчанию; текст Message обеих записей начинается с одинаковой X-координаты; `+` находится в gutter и не сдвигает JSON. |
| 2 | Раскрыть `[J01]`. | Корневой и вложенные `+` остаются в gutter; базовый текст форматированного JSON не сдвинут относительно обычного Message. |
| 3 | Сравнить обычные значения Time/Level/Thread/Component с прежним отображением. | В этих колонках постоянный gutter не добавляется; отступ есть только у строк с inline folding. |
| 4 | Пометить `[J01]` и `[J03]`, открыть Marked lines. | Whole text обеих отмеченных записей имеет тот же фиксированный gutter: plain и JSON начинаются с одной X-координаты. |
| 5 | Settings → View: выключить `Fixed folding gutter in Message`, Save. | Без переоткрытия в основной сетке и Marked lines plain text возвращается к прежнему нулевому отступу; folding-строки сохраняют inline gutter. |
| 6 | Включить `Fixed folding gutter in Message`, Save. | Фиксированное выравнивание Message и Marked lines восстановлено. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Вернуть `UseMessageFoldingGutter: true`.
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
