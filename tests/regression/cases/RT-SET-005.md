## Цель

Проверить сохранение настройки и live-переключение gutter.

## Проверяемые требования

- `REQ-JSN-09` — UseMessageFoldingGutter по умолчанию резервирует фиксированный gutter для всех строк Message и текста Marked lines; другие колонки сохраняют отступ только у folding-строк; false восстанавливает прежнее поведение везде.
- `REQ-SET-02` — Ручное изменение `appsettings.yaml` подхватывается без перезапуска (цвета, форматы, обнаружение бинарных данных, маппинги, символы, профили, gutter Message).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `json-xml.log`, пометить `[J01]` и `[J03]`, открыть Marked lines и Settings → View. | `Fixed folding gutter in Message` включён по умолчанию; основная сетка и Marked lines используют фиксированный gutter. |
| 2 | Выключить флажок и нажать Cancel. | Отображение и `appsettings.yaml` не изменились; gutter остался включённым. |
| 3 | Выключить флажок и нажать Save. | В сетке и Marked lines восстановлен прежний отступ только у folding-строк; в YAML `UseMessageFoldingGutter: false`. |
| 4 | Перезапустить приложение и открыть те же документы. | Выключенное состояние сохранилось; plain text в Message и Marked lines без постоянного gutter. |
| 5 | Включить флажок, Save, затем во внешнем редакторе записать `UseMessageFoldingGutter: false`. | Значение снова false применилось к открытой сетке и Marked lines без перезапуска/переоткрытия. |
| 6 | Во внешнем редакторе вернуть `UseMessageFoldingGutter: true`. | Фиксированный gutter восстановлен в обоих представлениях; YAML содержит `true`. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
