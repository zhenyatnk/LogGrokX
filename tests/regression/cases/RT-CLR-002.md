# RT-CLR-002. Пользовательское правило цвета

| Поле | Значение |
|---|---|
| ID | `RT-CLR-002` |
| Область | CLR — Правила цвета |
| Приоритет | P2 |
| Тип | Функциональный |
| Требования | `REQ-CLR-03`, `REQ-CLR-02` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |
| Данные | `%RT%\testdata\colors.log` |
| Ориентировочная длительность | 5 мин |
| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Проверить редактирование правил.

## Проверяемые требования

- `REQ-CLR-03` — Добавление/изменение/удаление правил в Settings → Profiles → Colors (и в YAML) применяется к открытым документам.
- `REQ-CLR-02` — ForegroundColor и BackgroundColor (именованные цвета и `#AARRGGBB`) поддерживаются; правила видны в обеих темах.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `colors.log`. Settings → Profiles → `Classic` → Colors: добавить правило `custom-rule-token`, Foreground `#FF0000FF`, Background `Yellow`, поставить первым. Save. | `[C11]` синим по жёлтому без переоткрытия файла. |
| 2 | Переместить правило в конец списка, Save. | `[C11]` по-прежнему окрашен (других совпадений нет). |
| 3 | Добавить правило `ERR` с Foreground `Green` в начало, Save. | `[C01]`, `[C07]`, `[C09]` зелёные (первое совпадение). |
| 4 | Ввести невалидный regex `([` в правило. | Ошибка валидации показана, сохранение блокируется или предлагается исправление; аварии нет. |
| 5 | Удалить добавленные правила, Save. | Цвета как в RT-CLR-001. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Удалить добавленные правила.
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
