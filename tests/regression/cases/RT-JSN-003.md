## Цель

Регрессия #31: перенос строки с табуляцией в сообщении.

## Проверяемые требования

- `REQ-JSN-04` — Многострочный JSON в строках продолжения (в т.ч. с табуляцией) распознаётся как часть Message и форматируется (#31).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `json-xml.log`, найти `[J04]`. | Запись `[J04]` включает 4 строки продолжения (`\t"alpha": 1,` … `}`) в колонке Message, а не отдельные неформатированные строки. |
| 2 | Раскрыть JSON `[J04]`. | Отформатирован объект `alpha`, `beta`, `gamma`. |
| 3 | Открыть `classic-multiline.log`, проверить `[M02]`. | Стек (`at LogGrokX.Demo...`) и `continuation-only-token-QX7` входят в Message записи `[M02]`; Time/Level/Thread заполнены из первой строки. |
| 4 | Скопировать `[M02]` (`Ctrl+C`). | В буфере многострочный текст записи без многоточий. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
