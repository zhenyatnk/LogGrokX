## Цель

Проверить локализацию.

## Проверяемые требования

- `REQ-LNG-01` — Языки интерфейса: System language, English, Русский, Deutsch, Français, Español, 日本語, Polski, Português (Brasil); смена после перезапуска (`The interface language changes after restarting the application.`).
- `REQ-LNG-02` — Содержимое логов, имена полей/колонок, имена профилей и ключи YAML не переводятся; неподдерживаемый системный язык → English.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Settings → View → Language: проверить список. | `System language` и 8 языков: English, Русский, Deutsch, Français, Español, 日本語, Polski, Português (Brasil). |
| 2 | Выбрать Русский, Save. | Сообщение `The interface language changes after restarting the application.` (на текущем языке). |
| 3 | Перезапустить. | Меню, настройки, окна на русском; содержимое лога, заголовки колонок (`Time`, `Level`, …), имена профилей не переведены. |
| 4 | Повторить для de, fr, es, ja, pl, pt-BR (быстрая проверка главного окна и Settings). | Тексты переведены, нет обрезанных/перекрывающихся подписей; японские символы отображаются. |
| 5 | Выбрать `System language` при языке Windows, отличном от поддерживаемых (например, `it-IT`, если доступен), перезапустить. | Интерфейс на English. |
| 6 | Вернуть English. | `Language: en` в YAML. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
