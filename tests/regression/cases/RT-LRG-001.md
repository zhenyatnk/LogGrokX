## Цель

Проверить заявленную поддержку больших файлов.

## Проверяемые требования

- `REQ-LRG-01` — Большие файлы (≥1 ГБ) открываются потоково: интерфейс отзывчив во время индексации, отображается прогресс.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | `& "%RT%\tools\New-LargeLog.ps1" -Path $env:TEMP\lgx-large.log -SizeMB 1024` — запомнить `Lines`. | Файл создан. |
| 2 | Открыть файл и засечь время до появления первых строк. | Первые строки (`[L-FIRST]`) видны ≤ 3 с; индикатор прогресса загрузки виден. |
| 3 | Во время индексации прокручивать сетку колесом и перетаскивать полосу прокрутки. | Интерфейс отвечает (нет «Не отвечает» в заголовке), задержки ≤ 1 с. |
| 4 | Дождаться окончания загрузки; перейти в конец (перетащить ползунок вниз до упора). | Видна строка `[L-LAST] large log end line=<Lines-1>`. |
| 5 | Засечь время от открытия до исчезновения индикатора прогресса (полная индексация). | Время полной загрузки записано в `metrics`; при наличии отчёта предыдущего прогона на том же стенде — не хуже прежнего более чем на 20% (#134). |
| 6 | Проверить потребление памяти процессом после загрузки и после навигации в конец: `Get-Process LogGrokX \| select WS, PrivateMemorySize64`. | Рабочий набор и Private Memory меньше 50% размера файла (для 1 ГБ — < 512 МБ, #112); оба значения фиксируются в отчёте. |
| 7 | Выбрать на таймлайне диапазон в середине файла, затем снять выбор; выполнить переход `Ctrl+End` и `Ctrl+Home`. | Фильтр по времени и навигация работают на уплотнённых индексах: строки диапазона показаны без пропусков, переходы ≤ 2 с, память не выросла более чем на 10%. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Краевые случаи и примечания

- Числовые замеры (время, память) записываются в `metrics` результата кейса.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- `Remove-Item $env:TEMP\lgx-large.log`
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
