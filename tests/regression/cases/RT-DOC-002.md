## Цель

Проверить drag & drop (включая папки).

## Проверяемые требования

- `REQ-DOC-02` — Drag & drop одного или нескольких файлов, а также папки (рекурсивно все файлы).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Из Проводника перетащить файл `tab-basic.log` в окно (на экран приветствия). | Открыта вкладка `tab-basic.log`. |
| 2 | Перетащить сразу два файла `threads.log` и `colors.log` на область сетки открытого документа. | Открыты ещё две вкладки. |
| 3 | Перетащить папку `%RT%\testdata\merge` целиком. | Открыты все файлы папки рекурсивно: `merge-a.log`, `merge-b.log`, `merge-plain.txt`, `merge-unordered.log` (4 вкладки). |
| 4 | Повторно перетащить `tab-basic.log`. | Новая вкладка не создаётся — активируется существующая. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
