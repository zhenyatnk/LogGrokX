## Цель

Проверить маппинг в структурированных данных.

## Проверяемые требования

- `REQ-VM-03` — В JSON строки маппятся внутри кавычек, числа — комментарием `5 /*five*/`, ключи не маппятся; в XML — текст, атрибуты, CDATA с экранированием; сворачивание сохраняется.
- `REQ-VM-04` — Маппинг меняет только отображение и копирование; поиск, фильтры, цвета и индексы работают по исходным значениям.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | С импортированными списками из RT-VM-001 открыть `mapping.log`, раскрыть JSON `[V05]`. | `code`: `5 /*five*/`; `name`: `"0x00001(type 1)"`; ключ `"0x00001"` не изменён; `list`: `[5 /*five*/, "TYPE_A(upper A)"]`; JSON сворачивается. |
| 2 | Раскрыть XML `[V06]`. | `a="0x00001(type 1)"`, `<v>0x00002(type 2)</v>`, CDATA `0x00001(type 1)`; XML сворачивается. |
| 3 | Искать `type 1`. | 0 совпадений (поиск по исходным значениям). |
| 4 | Искать `0x00001`. | Совпадения в `[V01]`, `[V02]`, `[V05]`, `[V06]`. |
| 5 | Фильтр Component: значение `0x00001` в списке фильтра без маппинга. | Фильтр работает по исходным значениям. |
| 6 | Скопировать `[V01]`. | Буфер содержит отображаемый текст с маппингом; `Copy as native` — исходный. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
