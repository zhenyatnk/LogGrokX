## Цель

Регрессия #58: маппинг значений.

## Проверяемые требования

- `REQ-VM-01` — Значение из списка маппинга отображается как `value(mapping)`; совпадение только целым токеном; длиннейшее значение выигрывает; при равных — первый список.
- `REQ-VM-02` — Enabled, Ignore case и Fields (через запятую, пусто = все поля) у списка.
- `REQ-VM-05` — Import JSON... (объект списка, массив списков, плоский объект `{value: mapping}`; замена по имени), Export list..., Export all...; ошибки импорта.
- `REQ-VM-06` — Предпросмотр Preview, валидация (пустое значение, дубликаты) и применение после Save к открытым строкам без переоткрытия (#58).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Settings → Value mappings → `Import JSON...` → выбрать `vm-list.json`, `vm-array.json`, `vm-plain.json`. | Сообщение `Imported 5 list(s) with … value(s). Save to apply.`; списки `Reg-Types`, `Reg-Case`, `Reg-Phrase`, `Reg-Second`, `vm-plain`. |
| 2 | Save. Открыть `mapping\mapping.log`. | `[V01]` Message: `request type 0x00001(type 1) failed: 0x80070005(ACCESS_DENIED_PLAIN)`; Component `0x00001` НЕ размечен (Fields = Message). |
| 3 | Проверить `[V02]`. | `0x000010`, `x0x00001`, `0x00001x` без маппинга (только целый токен). |
| 4 | Проверить `[V03]`. | `TYPE_A(upper A)`, `type_a` без маппинга (Ignore case выключен). |
| 5 | Проверить `[V04]`. | `disk full(long wins)` и `disk(short)` — длиннейшее значение. |
| 6 | Проверить `[V07]`. | `0x00003(first list)` — первый список. |
| 7 | Проверить `[V08]`. | `AMP_CODE(a<b & "c")`. |
| 8 | Выключить `Enabled` у `Reg-Phrase`, Save (без переоткрытия). | `[V04]`, `[V07]` сразу без маппинга `Reg-Phrase`; `[V07]` теперь `0x00003(second list)`. |
| 9 | Включить `Ignore case` у `Reg-Case`, Save. | `type_a(upper A)`. |
| 10 | В поле Preview ввести `code 0x00002 and disk full`. | `code 0x00002(type 2) and disk full(long wins)`. |
| 11 | Включить `Enabled` у `Reg-Phrase`, выбрать в списке `Reg-Phrase`; текст Preview не менять. | Preview объединяет выбранный список с остальными включёнными: `code 0x00002(type 2) and disk full(long wins)`, значение из `Reg-Types` размечено (#119). |
| 12 | Не меняя текст Preview, выключить `Enabled` у `Reg-Types`, затем включить обратно. | Preview обновляется сразу после каждого переключения: без `Reg-Types` — `code 0x00002 and disk full(long wins)`, после включения — снова с `(type 2)`. |
| 13 | Выбрать `Reg-Types`, изменить маппинг `0x00002` на `type two`, вернуться к `Reg-Phrase`. | Preview показывает `code 0x00002(type two) …` без повторного ввода текста. |
| 14 | Быстро набрать в Preview строку из 200 символов и удалить её `Backspace` с автоповтором. | Ввод без заметных задержек (≤ 100 мс на символ), UI не зависает; после остановки ввода Preview показывает результат для итогового текста (PR #150). |
| 15 | Cancel. | Изменения `Reg-Types` не сохранены. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
