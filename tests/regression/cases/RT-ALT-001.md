## Цель

Проверить базовое добавление слов Alt+кликом.

## Проверяемые требования

- `REQ-ALT-01` — Удержание Alt подсвечивает текст под курсором, который будет добавлен в поиск.
- `REQ-ALT-02` — Alt+клик: первый клик начинает regex-поиск, последующие добавляют `.*слово`.
- `REQ-ALT-05` — Существующий не-regex текст в поле экранируется перед добавлением; для форматированного JSON/XML добавляется исходная подстрока.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `search.log`, очистить поиск. Зажать `Alt` и навести курсор на слово `beta` в `[S14]`. | Слово `beta` подсвечено как кандидат. |
| 2 | Alt+клик по `beta`. | В поле поиска `beta`, regex включён, 1 совпадение `[S14]`. |
| 3 | Alt+клик по `delta` в той же строке. | Поле: `beta.*delta`, 1 совпадение. |
| 4 | Очистить поиск, выключить regex, ввести `a+b` (обычный текст). Alt+клик по `price` в `[S08]`. | Существующий текст экранирован: `a\+b.*price` (regex включён). |
| 5 | Отпустить Alt. | Подсветка кандидата исчезла. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
