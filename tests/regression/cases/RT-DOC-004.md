## Цель

Проверить, что манипуляции вкладками не теряют состояние документа.

## Проверяемые требования

- `REQ-DOC-05` — Вкладки AvalonDock: переключение, перестановка, закрытие, плавающее/закреплённое состояние без потери состояния документа.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `tab-basic.log`, `threads.log`, `colors.log`. В `tab-basic.log` пометить строку `[T05]` (клик по булавке слева). | Строка помечена (булавка активна). |
| 2 | Перетащить вкладку `colors.log` на первое место. | Порядок вкладок изменился, содержимое не перезагружено. |
| 3 | Вытащить вкладку `threads.log` за пределы панели вкладок (плавающее окно), затем вернуть её в док. | Документ отображается в плавающем окне и после возврата; содержимое и прокрутка сохранены. |
| 4 | Вернуться на `tab-basic.log`. | Пометка `[T05]` сохранена. |
| 5 | Закрыть вкладку `colors.log` крестиком, затем средней кнопкой мыши закрыть `threads.log` (если поддерживается). | Вкладки закрываются; при закрытии последней вкладки показывается экран приветствия. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
