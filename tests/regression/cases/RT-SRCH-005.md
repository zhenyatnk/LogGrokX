## Цель

Проверить работу нескольких поисков.

## Проверяемые требования

- `REQ-SRCH-06` — Несколько вкладок поиска (New search), закрытие вкладки поиска.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `search.log`, искать `alpha`. | 3 совпадения: `[S14]`, `[S16]`, `[S18]`. |
| 2 | Нажать `New search`, искать `delta`. | Новая вкладка результатов; 3 совпадения (`[S14]`, `[S17]`, `[S18]`). Первая вкладка с `alpha` сохранилась. |
| 3 | Переключиться между вкладками поиска. | Подсветка и F3 следуют активной вкладке поиска. |
| 4 | Закрыть вкладку `delta`. | Активна вкладка `alpha`; результаты не потеряны. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.
