| Требования | `REQ-JSN-03` |

| Дефекты (регрессия) | — |

## Цель

Проверить общее состояние сворачивания.

## Проверяемые требования

- `REQ-JSN-03` — Состояние сворачивания общее для сетки, результатов поиска и Marked lines одного документа.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `json-xml.log`, пометить `[J08]`, искать `login`. | `[J08]` в сетке, результатах поиска и Marked lines. |
| 2 | Раскрыть JSON `[J08]` в сетке. | В результатах поиска и Marked lines JSON `[J08]` тоже раскрыт. |
| 3 | Свернуть в Marked lines. | Свернулся и в сетке, и в результатах поиска. |
| 4 | Прокрутить сетку вниз и обратно. | Состояние сохранилось. |
| 5 | Три раза подряд раскрыть и свернуть `[J08]` в результатах поиска, затем один раз в сетке. | После каждого действия состояние совпадает во всех трёх представлениях; второе представление (сетка или поиск) перерисовывается сразу, без прокрутки; исключений нет. |
| 6 | Раскрыть `[J02]` (массив) в Marked lines, предварительно пометив его. | Массив раскрыт и в сетке; состояние массива разделяется так же, как у объекта. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
