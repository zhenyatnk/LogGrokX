# RT-FMT-006. Некорректный формат в выбранном профиле

| Поле | Значение |
|---|---|
| ID | `RT-FMT-006` |
| Область | FMT — Форматы логов и автоопределение |
| Приоритет | P1 |
| Тип | Негативный |
| Требования | `REQ-FMT-07` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.badprofile.yaml` |
| Данные | `%RT%\testdata\tab-basic.log` |
| Ориентировочная длительность | 5 мин |
| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Проверить обработку невалидного формата.

## Проверяемые требования

- `REQ-FMT-07` — Некорректный формат (невалидный regex / неизвестное индексируемое поле) пропускается при открытии файла без аварии.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Закрыть приложение, подложить `testdata\config\appsettings.badprofile.yaml` как `%APP%\appsettings.yaml`, запустить. | Приложение стартует без аварии; выбран профиль `Broken`. |
| 2 | Открыть `tab-basic.log`. | Невалидный формат пропущен (в диагностическом логе предупреждение `Skipping invalid log format`); файл открыт как текст (одна колонка с целой строкой), без аварии. |
| 3 | Переключить профиль на `Classic` через селектор. | Документ перечитан, колонки Classic появились. |
| 4 | Открыть Settings → Profiles → Log formats профиля `Broken` и нажать `Save`. | Сохранение блокируется: в списке ошибок `Profile 'Broken', log format 1: A log format has an invalid regular expression.`; автоисправление недоступно для regex формата. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Восстановить эталонный `appsettings.yaml`.
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
