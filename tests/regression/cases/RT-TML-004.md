## Цель

Проверить граничные варианты времени.

## Проверяемые требования

- `REQ-TML-03` — Без меток времени (или при немонотонном времени с датой) таймлайн работает в режиме номеров строк.
- `REQ-TML-07` — Одинаковое время у всех строк и файл из одной строки не ломают таймлайн.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `time\unordered.log` (строка `[U06]` на 5 с раньше, время с датой). | Таймлайн переходит в режим номеров строк: при наведении `Line N`. |
| 2 | Открыть `time\same-time.log` (20 строк с одинаковым временем). | Нет аварий; таймлайн отображается; выбор диапазона не скрывает строки «случайно». |
| 3 | Открыть `time\single-line.log`. | Нет аварий; таймлайн с одной точкой; наведение показывает время/строку. |
| 4 | Открыть `encoding\empty.log`. | Нет аварий; таймлайн пустой. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
