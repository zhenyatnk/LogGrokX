## Цель

Проверить команды вкладки документа.

## Проверяемые требования

- `REQ-DOC-04` — Контекстное меню вкладки: Copy Filename, Copy Full Path, Open Containing Folder.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `tab-basic.log`. Правый клик по заголовку вкладки. | Меню содержит `Copy Filename`, `Copy Full Path`, `Open Containing Folder`. |
| 2 | Выбрать `Copy Filename`, выполнить `Get-Clipboard`. | В буфере `tab-basic.log`. |
| 3 | Выбрать `Copy Full Path`, выполнить `Get-Clipboard`. | В буфере полный путь `%RT%\testdata\tab-basic.log`. |
| 4 | Выбрать `Open Containing Folder`. | Открывается Проводник в папке `testdata` с выделенным/видимым файлом `tab-basic.log`. Закрыть Проводник. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Закрыть окно Проводника.
- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
