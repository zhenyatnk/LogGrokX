| ID | `RT-LCH-002` |
| Область | LCH — Запуск и единственный экземпляр |

| Требования | `REQ-LCH-02` |

| Данные | `%RT%\testdata\tab-basic.log`<br>`%RT%\testdata\search.log` |
| Ориентировочная длительность | 5 мин |
| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Проверить открытие нескольких документов из командной строки.

## Проверяемые требования

- `REQ-LCH-02` — Пути из командной строки открываются как документы при запуске (несколько файлов).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Закрыть LogGrokX. В PowerShell выполнить `& "%APP%\LogGrokX.exe" "%RT%\testdata\tab-basic.log" "%RT%\testdata\search.log"`. | Открыто одно окно с двумя вкладками: `tab-basic.log` и `search.log`. Активна последняя открытая вкладка (`search.log`). |
| 2 | Переключиться на вкладку `tab-basic.log`. | Отображаются 16 строк с маркерами `[T01]`…`[T16]`, колонки `Time`, `Thread`, `Severity`, `Component`, `Message`. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
