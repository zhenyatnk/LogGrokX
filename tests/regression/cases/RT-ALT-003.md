## Цель

Проверить Alt+клик для форматированных блоков.

## Проверяемые требования

- `REQ-ALT-05` — Существующий не-regex текст в поле экранируется перед добавлением; для форматированного JSON/XML добавляется исходная подстрока.
- `REQ-SRCH-08` — Подсветка совпадений в сетке; при regex с `.*` поглощённый текст приглушён (25% светлая / 30% тёмная тема).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `json-xml.log`, развернуть JSON строки `[J08]`. | JSON отформатирован с отступами. |
| 2 | Alt+клик по ключу `"action"` в развёрнутом JSON. | В поиск добавлена исходная подстрока `"action":"login"` (без добавленных форматированием пробелов); совпадение 1. |
| 3 | Искать `"ip":"10.0.0.1"` (обычный текст). | Совпадение подсвечено и в форматированном виде. |
| 4 | Развернуть XML `[X01]`, Alt+клик по `Widget`. | Добавлено `Widget`, 1 совпадение. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
