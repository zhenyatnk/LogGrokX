## Цель

Проверить вывод версии для скриптов и диагностики.

## Проверяемые требования

- `REQ-LCH-06` — Ключ --version печатает версию и завершает процесс без открытия окна.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Закрыть LogGrokX. Выполнить `Start-Process "%APP%\LogGrokX.exe" -ArgumentList '--version' -RedirectStandardOutput $env:TEMP\lgx-ver.txt -Wait -NoNewWindow; Get-Content $env:TEMP\lgx-ver.txt`. | Процесс завершился без открытия окна. В файле одна строка с версией (для локальной сборки — `0.0` или `0.0.0`, для релиза — номер версии релиза). |
| 2 | Сравнить версию с окном Support (запустить приложение, нажать `?`). | Версия совпадает со строкой `Version` в окне Support. |
| 3 | Повторить с ключом `--VERSION` (верхний регистр). | Поведение идентично (ключ без учёта регистра). |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- `lgx-ver.txt`
- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.

## Очистка

- Закрыть открытые документы.
- Восстановить исходную конфигурацию, если она менялась (см. README).
