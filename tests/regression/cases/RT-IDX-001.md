## Цель

Проверить работу ширины колонок.

## Проверяемые требования

- `REQ-IDX-03` — Ширина колонок: двойной клик по разделителю заголовка подгоняет ширину; Message расширяется и сохраняет ширину.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `binary\binary.log`. Сузить колонку `Component` перетаскиванием до ~20 px. | Значения обрезаны. |
| 2 | Двойной клик по правому разделителю заголовка `Component`. | Ширина подогнана под самое длинное видимое значение. |
| 3 | Расширить колонку `Message` вправо, прокрутить сетку вниз и обратно. | Ширина Message сохраняется при прокрутке. |
| 4 | Переключиться на другую вкладку и вернуться. | Ширины колонок сохранены. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.

## Артефакты для отчёта

- Скриншот после каждого шага с проверкой UI (`step-NN.png`).
- Содержимое буфера обмена/файлов для шагов с копированием и сохранением.
