# RT-XOR-001. XOR-маскированные логи

| Поле | Значение |
|---|---|
| ID | `RT-XOR-001` |
| Область | XOR — XOR-маскированные логи |
| Приоритет | P1 |
| Тип | Функциональный |
| Требования | `REQ-XOR-01`, `REQ-XOR-02`, `REQ-TRN-02` |
| Профиль | `Classic` |
| Конфигурация | `testdata/config/appsettings.regression.yaml` |
| Данные | `%RT%\testdata\xor\xor-ef.log`<br>`%RT%\testdata\xor\xor-5a.log`<br>`%RT%\testdata\transform\transform-xor.log` |
| Ориентировочная длительность | 5 мин |
| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Проверить XOR.

## Проверяемые требования

- `REQ-XOR-01` — Файлы, замаскированные однобайтовым XOR (XorMask формата), открываются и ищутся как обычные.
- `REQ-XOR-02` — Файл с другим XOR-ключом не определяется форматом с XorMask и не вызывает аварию.
- `REQ-TRN-02` — Base64DecodeFormatJson декодирует и форматирует JSON (в т.ч. для XOR-формата).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `xor\xor-ef.log`. | Файл расшифрован: 10 строк `[XR01] secure line 1` … `[XR10] secure line 10`, колонки Thread `0x0F03`, Severity `INF`, Component `Secure`. |
| 2 | Искать `secure line 7`. | 1 совпадение `[XR07]`. |
| 3 | Фильтр Severity, таймлайн. | Работают как для обычного лога. |
| 4 | Открыть `transform\transform-xor.log`. | `[TR03]`: Base64 заменён отформатированным JSON `{"seats":5,"owner":"axx"}`; `[TR04] plain xor line` читается. |
| 5 | Открыть `xor\xor-5a.log`. | Формат с XorMask 0xef не определён; файл открыт как неструктурированный текст (нечитаемые символы), аварии нет. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
