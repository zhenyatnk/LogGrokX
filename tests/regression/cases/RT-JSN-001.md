## Цель

Проверить форматирование JSON и исходное свёрнутое состояние (#111).

## Проверяемые требования

- `REQ-JSN-01` — JSON-объекты и массивы в сообщении распознаются, форматируются с отступами и сворачиваются; в свёрнутом виде занимают одну строку.
- `REQ-JSN-02` — Контекстное меню Folding: Expand All, Collapse All, Expand recursively, Collapse recursively.
- `REQ-JSN-05` — Некорректный JSON отображается как текст без аварии; текст до и после JSON сохраняется; несколько JSON в строке.

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `json-xml.log`. | Строки `[J01]`, `[J02]`, `[J08]`, `[J09]` содержат свёрнутый JSON в одну строку с индикатором раскрытия; ни одна запись не открыта развёрнутой (#111). `[J02]` свёрнут целиком как внешний массив, а не как три отдельных объекта. |
| 2 | Проверить `[J05]` (большой JSON, ~70 КБ) и `[J07]` (маленький). | Оба изначально свёрнуты: состояние по умолчанию не зависит от размера JSON (#111). |
| 3 | Раскрыть JSON в `[J01]`. | JSON отформатирован с отступами: `id`, `name`, `items` `[1,2,3]`, `nested`; текст `payload` до и `end` после сохранены. |
| 4 | Контекстное меню → Folding → `Collapse All`, затем `Expand recursively` на `[J01]`. | Сначала всё свёрнуто; затем раскрыты все уровни `nested.a.b.c`. |
| 5 | `Collapse recursively` на `[J01]`, затем `Expand All`. | Все вложенные регионы свёрнуты; затем все JSON документа раскрыты. |
| 6 | Раскрыть `[J02]`, затем свернуть его индикатором внешнего массива. | Массив `[{"k":1},{"k":2},{"k":3}]` отформатирован, у внешнего массива и у каждого объекта свой индикатор; после сворачивания массив снова занимает одну строку; аварии нет (исторический дефект `[{}, {}]`). |
| 7 | Проверить `[J03]`. | Некорректный JSON показан как обычный текст, индикатора раскрытия нет. |
| 8 | Проверить `[J09]`. | Два независимых JSON (`{"first":1}` и `{"second":{"x":2}}`) сворачиваются раздельно, текст `and` между ними сохранён. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
