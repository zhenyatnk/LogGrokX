# RT-SAV-001. Сохранение и применение сохранённого поиска

| Поле | Значение |
|---|---|
| ID | `RT-SAV-001` |
| Область | SAV — Сохранённые поиски |

| Дефекты (регрессия) | — |
| Внешние ресурсы / ручные действия | Нет |

## Цель

Проверить сохранение поисков.

## Проверяемые требования

- `REQ-SAV-01` — Сохранение текущего поиска (Save current search…) с именем; подтверждение замены при совпадении имени.
- `REQ-SAV-02` — Применение сохранённого поиска из выпадающего списка с фильтром.
- `REQ-SAV-05` — Сохранённые поиски сохраняются между запусками (SavedSearches.json).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `search.log`, включить regex, ввести `payment\s+failed`. | 3 совпадения. |
| 2 | Открыть меню сохранённых поисков у поля поиска → `Save current search…`, имя `RT payments`, сохранить. | Поиск сохранён. |
| 3 | Очистить поиск. Открыть список сохранённых поисков, в фильтре ввести `pay`, выбрать `RT payments`. | Поле поиска заполнено `payment\s+failed`, regex включён, 3 совпадения. |
| 4 | Снова `Save current search…` с тем же именем `RT payments` и другим шаблоном `failed`. | Показано `A saved search with this name already exists. Replace it?` с кнопками `Replace`/`Cancel`. Нажать `Replace`. |
| 5 | Перезапустить приложение, открыть список сохранённых поисков. | `RT payments` присутствует с шаблоном `failed`; в `SavedSearches.json` есть запись. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
