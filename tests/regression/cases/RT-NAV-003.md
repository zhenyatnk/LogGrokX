## Цель

Регрессия #22: горизонтальная прокрутка вторым колесом.

## Проверяемые требования

- `REQ-NAV-04` — Горизонтальная прокрутка сетки, включая вторую ось колеса/тачпада (#22).

## Предусловия

- Выполнена базовая подготовка окружения из [README](../README.md#подготовка-окружения) (конфигурация, чистые данные пользователя).

## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `binary\binary.log`, сузить окно до 800 px ширины. | Есть горизонтальная полоса прокрутки. |
| 2 | Прокрутить горизонтально вторым колесом мыши/жестом тачпада (или Shift+колесо). | Сетка прокручивается горизонтально плавно, вертикальная позиция не меняется. |
| 3 | Перетащить горизонтальный ползунок до конца. | Видна правая часть длинных сообщений; заголовки колонок прокручиваются синхронно. |

## Критерии прохождения

- Фактический результат каждого шага совпадает с ожидаемым.
- Нет аварийного завершения, зависаний UI > 5 с и необработанных исключений в логе `%LOCALAPPDATA%\LogGrokX\`.
